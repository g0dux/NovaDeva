# Nova Deva

RPG de ação em mundo aberto para **Godot 4.x**: sobrevivência estilo [Outward](https://www.outwardgame.com/), combate soulslike e um mundo fantástico mais macabro — Devas na superfície, Asuras no subsolo.

## 🎮 Projeto Jogável

**O projeto Godot está configurado e funcional com combate corpo a corpo, IA de inimigos, inventário e sobrevivência!** 

Para rodar o jogo:
1. Abra este repositório no Godot Engine 4.3+
2. Pressione F5 ou clique em Play
3. Use **WASD** para mover, **Espaço** para pular, **Clique Esquerdo** para atacar
4. Use **E** para coletar itens, **I** para abrir inventário
